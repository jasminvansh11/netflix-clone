# 🎬 Netflix Clone

A responsive Netflix landing page clone built using **HTML5** and **CSS3**. This project recreates the Netflix homepage with a modern user interface, hero section, feature sections, FAQ area, and responsive design for desktop, tablet, and mobile devices.

## 🚀 Live Demo

🔗 https://jasminvansh11.github.io/netflix-clone/

## 📌 Features

* Netflix-inspired landing page
* Responsive navigation bar
* Hero section with email signup form
* TV streaming showcase with video animation
* Download shows offline section
* Multi-device streaming section
* Kids profile section
* FAQ section with interactive design
* Responsive footer with useful links
* Mobile-friendly layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Responsive Design
* Embedded Videos

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/jasminvansh11/netflix-clone.git
```

Navigate to the project folder:

```bash
cd netflix-clone
```

Open `index.html` in your browser.
